Featured Projects

PS 2nd Place DAPTA

Dapta

2nd Place, LA Hacks AI Hackathon · Oct 2026

Teaches a small open-source AI model a repetitive task once, so it handles that task faster, cheaper, and more accurately afterward.

Tasks like NDA review, invoices, and form filling get their own lightweight LoRA adapter on an open-weight Qwen model. A router swaps in the right adapter for familiar requests and falls back to the base model for anything new. In the NDA-review proof of concept (Qwen3-1.7B, held-out test set), the adapter was 85% accurate vs 39% for the model given the full written instructions, scored 95% vs 73% on individual review criteria, and used 87% fewer prompt tokens.

LoRA PEFT Qwen vLLM Agents

PS In Progress DUCKDB LEARNED OPTIMIZER

DuckDB Learned Optimizer

C++ · Experimental

Uses machine learning to help the DuckDB database predict how much data a query will touch, so it can choose faster ways to run it.

Learned cardinality estimation for DuckDB's join-order optimizer. A C++ hook on DuckDB's cardinality-estimation path supports native, shadow, learned, hybrid, and adaptive modes, and a Python pipeline trains XGBoost estimators and exports them to ONNX with parity checks. In-engine ONNX inference and a Thompson Sampling selector for adaptive plan choice are in progress; no benchmark results yet.

C++ DuckDB ONNX Query Optimization Bandits

PS Live Demo MEETING ASSISTANT

Meeting Assistant

React · Groq · Whisper

An AI sidekick for live meetings: it writes down what's said, suggests what to ask or say next, and answers questions about the conversation.

Real-time meeting assistant that transcribes live audio or uploaded recordings with Whisper Large V3, surfaces three contextual suggestions every 30 seconds, and answers questions in a streaming chat grounded in the transcript.
