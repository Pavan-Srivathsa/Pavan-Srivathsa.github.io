CE

DuckDB Learned Optimizer

C++ · XGBoost → ONNX · Experimental

When a database joins several tables, it has to guess how many rows each step will produce (its "cardinality estimate") to decide which tables to join first. Bad guesses lead to slow join orders. This project plugs a machine-learned estimator into DuckDB's join-order optimizer, with safety modes that fall back to DuckDB's own estimates. Pick a query, change the settings, and run it.
